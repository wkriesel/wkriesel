People first, technology second.

## How I work

I start with the people who'll use the thing, not the tech. I listen for the problem underneath the request, build something small enough to test quickly, put it in front of real users, and change it based on what they tell me.

Stack I reach for: React, TypeScript, Python, Firebase, and plain HTML when that's all the job needs.
